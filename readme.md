# zsfx — универсальный sfx-модуль

Проект `ZipSFX` — лёгкий самораспаковывающийся SFX-модуль для Windows/.NET, позволяющий:

- создавать SFX-файлы: объединять исполняемый модуль и ZIP-архив в один файл (`module.exe` + `archive.zip` → `archive.exe`);
- распаковывать присоединённый ZIP, поддерживает методы хранения (0) и дефлат (8);
- работать как утилита распаковки при запуске без аргументов (если к exe присоединён zip).

особенности реализации
- прямое чтение структуры ZIP (EOCD, central directory, local headers) без использования внешних библиотек;
- подсчёт CRC-32 собственной реализацией (`ZipSFX/CustomCRC.cs`);
- безопасная распаковка: добавлена проверка путей для защиты от path traversal.

поддерживаемые сценарии запуска
- `zsfx.exe path\to\archive.zip` — создаёт SFX: копирует текущий модуль + содержимое `archive.zip` в `archive.exe`;
- `zsfx.exe [extractPath]` — распаковывает присоединённый архив в указанный каталог (по умолчанию текущий каталог);
- `zsfx.exe` — при наличии присоединённого ZIP распакует в текущий каталог, иначе выведет подсказку.

порядок работы
1. Поиск EOCD (End Of Central Directory) в конце файла (поиск в диапазоне 64K + фиксированная запись).
2. Чтение центрального каталога и записей.
3. Для каждой записи читается локальный заголовок и данные, затем данные распаковываются/копируются в целевой файл.

безопасность и ограничения
- path traversal: при распаковке проверяется, что целевые пути находятся внутри каталога распаковки — небезопасные записи игнорируются (логируется предупреждение);
- кодировка имён: учитывается флаг GPBF (bit 11) — если установлен, имена декодируются как UTF-8; иначе используется кодировка CP437 (IBM437) по умолчанию;
- поддержка многотомных ZIP ограничена — проект рассчитан на однотомные архивы; при обнаружении многотомника запись пропускается при поиске EOCD;
- не все расширенные опции ZIP (data descriptor, ZIP64) обработаны полностью — текущая реализация ориентирована на простые ZIP архиы; расширение поддержкой ZIP64 и data descriptor требует дальнейшей доработки.

сборка и запуск
1. Требуется .NET (версия, используемая в проекте: net9.0/net10.0). Собрать:

```powershell
dotnet build ZipSFX.slnx -c Release
```

2. Примеры:

```powershell
# создать sfx-архив
.
\bin\Debug\net10.0\zsfx.exe c:\path\to\archive.zip

# распаковать присоединённый архив в каталог
.
\bin\Debug\net10.0\zsfx.exe c:\target\dir
```
