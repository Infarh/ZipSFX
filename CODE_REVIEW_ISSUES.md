# Code review: найденные проблемы в ZipSFX

Ниже перечислены обнаруженные в ходе ревизии проблемы и предлагаемые исправления.

1. Безопасность распаковки: отсутствие проверки путей (path traversal). Риск записи файлов вне целевой директории.
2. Синтаксические ошибки в `ZipCentralDirectory` (`[]` и `[.. entries]`) — проект не собирается.
3. Ненадёжный поиск EOCD (End Of Central Directory): использование `MemoryMarshal.Read` и ранний возврат при многотомных архивах; недостаточная валидация смещений.
4. Обработка кодировки имён файлов: всегда используется UTF-8, не учитывается флаг GPBF (bit 11) и CP437.
5. Неправильная обработка раннего EOF при копировании ограниченного количества байт — может привести к неполному файлу без ошибки.
6. Дублирование проверки аргументов в `Program.cs` и неявный выбор пути exe (`GetCurrentAppFilePath`) — возможные проблемы при публикации single-file.
7. Стилевые рекомендации: унификация работы с буферами, явные исключения вместо общих catch, логирование ошибок.

План действий:

- Создать трекинговый файл (этот файл).
- Исправить `ZipCentralDirectory` (сборка).
- Защитить распаковку от path traversal.
- Улучшить поиск EOCD.
- Учитывать кодировку имён файлов (CP437/UTF-8).
- Исправить поведение при раннем EOF в `CopyLimitedWithCrc`.
- Убрать дублирование аргументов и улучшить получение пути exe.

Каждое исправление будет зафиксировано отдельным коммитом с пометкой `[fix]`.
